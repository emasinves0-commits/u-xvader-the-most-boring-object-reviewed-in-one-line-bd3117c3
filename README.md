The entry is a one-line, five-star review of the humble zip tie: "Five stars for the zip tie: it tightens with every tug, ignores every apology, and demands a blade for release. A tiny hostage situation." The joke is the one-way ratchet. A zip tie only ever gets tighter, so every pull makes things worse, nothing you say changes its mind, and the only way out is to bring a blade. That makes a dull bundling accessory read like a tiny hostage negotiation. `main.ts` validates the text (one line, 1–200 characters, not only whitespace) and writes it to `/output/entry.txt`.

Run with `node main.ts`.

## Judge-fit

**A boring, everyday object.** The zip tie is a strip of nylon that lives in a drawer or a toolbox. Nobody has ever been excited about one, and nobody has a favourite. It is exactly the sort of thing you use without noticing it exists, which is the brief.

**A real, recognisable detail.** The review leans on the one thing everyone knows about zip ties: the ratchet. Pull the tail and it clicks tighter. It never loosens by itself. Getting it off means scissors or a cutter. Anyone who has bundled cables or closed a bin bag has met all three behaviours, so the detail is something they have already felt.

**True.** The claims hold for an ordinary zip tie. It does tighten with each tug. Once the tooth has engaged it will not loosen by hand, and in normal use it comes off by cutting it. (Releasable zip ties exist, but they are a special variant, not the default object being reviewed.) "Ignores every apology" is the one joke-shaped line, and it is true in the sense that no amount of pleading changes how the mechanism behaves. The hostage framing is a comparison that follows from the facts, not an invented fact.

**One line, under 200 characters.** The entry is a single line of 137 characters, with no line breaks. It has a verdict (five stars), three escalating observations and a closing punchline, all inside the limit. `main.ts` checks both the length and the single-line rule before writing the file.

**Lands fast.** The structure is a standard review opener, then a list of three, then a short tag line. A reader gets the joke in one pass: "tightens", "ignores apologies" and "demands a blade" build a hostage scenario, and "A tiny hostage situation" names it. The final sentence is four words, so the punchline arrives last and is easy to take in.
